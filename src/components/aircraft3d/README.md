# 3D aircraft (parked)

Not used by the site for now (decision 2026-10-30: finish the site first, then decide).
Everything needed to bring it back is here:

- `HeroStage.tsx` — mounts the scene in the hero, pins it on scroll, picks a quality tier, shows the posters.
- `AircraftScene.tsx` — React Three Fiber scene that loads `public/models/goodfly-airliner*.glb`.
- `sceneConfig.json`, `orbit.ts`, `skyEnvironment.js`, `aircraftAnchors.json`, `quality.ts`, `sceneTextures.ts`.

The model itself is generated by `scripts/aircraft/` (`npm run build:aircraft`, `npm run test:model`).
To re-enable: render `<HeroStage>` inside `src/components/hero/Hero.tsx` with the poster images as children.
